# Resistor Color Code Calculator

A simple web application that calculates resistor values based on selected color bands.

The project was developed using **HTML, CSS, and JavaScript** as part of my early web development and electronics-related programming practice.

---

## ✨ Features

- Supports both **4-band** and **5-band** resistors
- Displays the selected color bands visually on the resistor
- Calculates the resistance value instantly
- Provides a simple and interactive user interface
- Runs directly in the browser without requiring a backend

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

---

## 🎯 Purpose

This project was created to practice fundamental web development concepts while learning how resistor color codes are used to determine resistance values.

It also helped me practice:

- JavaScript logic and calculations
- DOM manipulation
- User interaction handling
- Dynamic UI updates
- Basic electronics concepts

---

## 🚀 How to Run

1. Clone or download the repository.
2. Open `index.html` directly in your browser.
3. Alternatively, run the project using the **Live Server** extension in VS Code.
4. Select the resistor bands and their colors to calculate the resistance value.
